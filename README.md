# Corina’s Jungle Adventure

Four-scene interactive invitation with editable party details, personalized character stickers, GSAP animations, and a three-tap fossil reveal.

## Personalization

Edit `dist/invitation.config.js` for the name, age, date, time, venue, RSVP contact and five character asset paths. The current RSVP is informational text because no contact URL was supplied.

## Local preview

Serve `dist/` with any static web server. No build or dependency installation is required.

## Vercel

Import this repository and keep the repository root as the Root Directory. `vercel.json` selects the Other framework preset and serves `dist/`. Connect the `main` branch for automatic production deployments.
